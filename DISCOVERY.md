## ✨ Features At A Glance

### 🔨 Advanced Moderation & Escalation

- **Complete Mod Suite**: `/warn`, `/timeout`, `/removetimeout`, `/kick`, `/ban`, `/unban`, `/purge`, `/slowmode`, `/nickname`.
- **Automatic Warning Escalations**: Configurable threshold actions (e.g. 3 warnings = 1 hr timeout, 5 warnings = permanent ban) via `/escalation`.
- **Case Audit Trail**: Full moderation case history with `/case view`, `/case edit`, `/case delete`, and 1-click `/case export` (JSON audit export).
- **Staff Analytics**: Track server health and moderator activity with `/modstats`.
- **1-Click Server Presets**: Instantly apply curated security profiles (`casual`, `community`, `gaming`, `strict`) via `/preset apply`.

### 🛡️ Smart AutoMod & Anti-Raid Protection

- **Multi-Layer Content Filtering**: Automatic word filters, link blocklists, mass-mention spam protection, and chat velocity rate limits (`/automod`).
- **Granular Exemptions**: Exclude trusted staff roles or specific channels from AutoMod rules via `/automod exempt`.
- **Interactive Verification**: Safeguard your server against self-bots and raids with 1-click button or CAPTCHA verification panels (`/verify setup`).

### 🎫 Support Tickets & Interactive Role Panels

- **Support Tickets**: Deploy sleek ticket panels with private channels, automated permissions, and staff closure controls (`/ticket setup`, `/ticket close`).
- **Button Role Panels**: Create self-assignable role panels with customizable interactive buttons (`/rolepanel create`).
- **Custom Auto-Responders**: Configure bot replies triggered by custom keywords with variable substitution (`{user}`, `{server}`, `{member_count}`) via `/autoresponder`.

### 🗳️ Community Engagement & Utilities

- **Suggestions System**: Interactive suggestion submission with live 👍/👎 vote buttons and staff review workflows (`/suggest`).
- **Native Polls**: Create multi-option Discord native polls with custom duration timers (`/poll`).
- **Scheduled Tasks & Reminders**: Automate server announcements and personal reminders (`/automation`).
- **Activity Digests**: Generate 24h, 7d, and 30d community growth summaries (`/activitysummary`).

## 📋 4. Top.gg Submission Checklist & Verification Protocol

Before submitting your listing on Top.gg, ensure the following requirements are met:

- [x] **Web Server Online**: Web server accessible at `SITE_URL` with working `/health`, `/privacy`, and `/terms`.
- [x] **Top.gg Environment Variables Configured**:
  - `TOPGG_TOKEN` supplied in `.env` (used for automated server count posting).
  - `TOPGG_WEBHOOK_AUTH` supplied in `.env` (used for authenticating `/api/topgg/webhook`).
- [x] **Bot Permissions Scope**: Bot invited with slash command permissions (`bot` + `applications.commands`).
- [x] **Bot Online & Responsive**: Slash commands responding in under 3 seconds.
- [x] **Top.gg Webhook Endpoint Verified**: POST requests to `/api/topgg/webhook` returning `200 OK` when authorization header matches.
